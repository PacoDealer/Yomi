# Security

## Reporting a problem

Please **don't open a public issue** for security problems. Email **yomiappreader@gmail.com** with:

- what the problem is and what someone could do with it
- steps to reproduce it (a sample file, repository link or extension helps)
- the Yomi build number (**More → About**) and your iOS version

You'll get a reply within a week. Once a fix is in a TestFlight build, you're welcome to publish the details; say if
you'd like to be credited in the release notes.

## What's in scope

- the Yomi app and the code in this repository
- how Yomi downloads, checks and runs extensions (JavaScript plugins and Mihon extensions)
- opening untrusted files (CBZ, CBR, CB7, ZIP, EPUB) and backups
- the novel reader's handling of chapter HTML

Problems in a third-party repository or extension belong to the project that publishes it.

## Supported versions

Only the newest TestFlight build gets fixes.
