# Yomi Extensions Guide

Extensions connect Yomi to manga, manhwa, and novel sources. Without an extension installed, you can't browse or read anything.

---

## How to install an extension

### Option 1 — From the catalog (recommended)

1. Open **Browse** from the bottom navigation bar
2. Tap the **Extensions** tab
3. Find a source you want and tap **Install**
4. Go back to **Sources** — your new source appears there

That's it. Tap the source to start browsing.

---

### Option 2 — Install from URL

If you have a direct link to a `.js` plugin file:

1. Open **More** → **Plugins**
2. Tap the **+** button in the top-right corner
3. Paste the plugin URL and fill in a name
4. Tap **Install**

## Troubleshooting

**Extensions tab shows nothing**
The catalog failed to load. Pull down to refresh, or check your internet connection.

**A source shows an error after installing**
The source's website may have changed its layout. Check back for an update, or try a different source.

**Can I add my own source?**
Yes — use Option 2 above with any compatible `.js` plugin URL. Yomi supports Format A (manga) and Format B (LNReader novel) plugins.
