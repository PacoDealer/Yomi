# Yomi Extensions Guide

Extensions connect Yomi to manga, manhwa, and novel sources. Without one installed, you can't browse or read anything.

---

## How to install an extension

### Option 1 — From inside the app (easiest)

1. Open **Browse** from the bottom navigation bar
2. Tap the **Extensions** tab
3. Find a source and tap **Install**
4. Go back to **Sources** — your new source appears there

---

### Option 2 — Install manually from a URL

If the Extensions tab fails to load, you can install any source directly using its URL:

1. Open **More → Plugins**
2. Tap the **+** button (top-right)
3. Paste one of the URLs from the table below
4. Fill in a name and tap **Install**

---

## Troubleshooting

**Extensions tab shows nothing**
Pull down to refresh. If it still fails, use the manual URL method above — the sources are always available at the URLs listed here.

**A source shows an error after installing**
The source's website may have changed its layout. Try a different source or check back for an update.
